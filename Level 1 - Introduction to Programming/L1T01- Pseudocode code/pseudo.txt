Scenario 3
An algorithm that read an arbitary number of integers and then returns their arithmetic average.

1. Start algorithm
2. Create a variable called total and put 0 in it.
3. Create another variable called count and put it 0 in it.
4. Ask the user to enter a number.
5. If the user enters -1, stop asking for numbers and go to step 9.
6. Add the number to total.
7. Add 1 to count because another number has been entered.
8. Go back and ask the user fir another number.
9. Divide total by count to find the average.
10. Display the avergae.
11. End algorithm.

Pseudocode

Start

Set total to 0
Set count to 0

Ask the user to enter a number

WHILE the number is not -1
	Add the number to total
	Add 1 to count
	Ask the user to enter another number
END WHILE


Calculate average = total / count

Display the average
END
